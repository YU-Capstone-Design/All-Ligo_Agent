All-Ligo 개인정보처리방침

시행일: 2026-10-04

All-Ligo(이하 "서비스")는 소상공인의 홍보 콘텐츠를 AI 로 생성하는 대학 캡스톤 디자인 프로젝트입니다. 이 문서는 서비스의 콘텐츠 생성 서버가 Google 계정 권한을 어떻게 사용하는지 설명합니다.

1. Google 계정에서 사용하는 권한

서비스는 https://www.googleapis.com/auth/youtube.upload 권한 하나만 요청합니다. 이 권한은 서비스 운영팀이 소유한 YouTube 채널에 홍보 영상을 업로드하는 용도로만 사용합니다. 다른 사용자의 Google 계정 정보, 이메일, 연락처, 시청 기록 등은 요청하거나 수집하지 않습니다.

2. 보관하는 정보

업로드를 위해 Google 이 발급한 인증 토큰을 서비스 서버에만 보관합니다(서버 운영자만 읽을 수 있는 파일). 토큰은 영상 업로드 외의 목적으로 사용하지 않으며, 제3자에게 제공하거나 판매하지 않습니다.

3. Google API 서비스 사용자 데이터 정책 준수

서비스가 Google API 로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회 및 삭제

권한을 허용한 계정은 언제든지 Google 계정 → 타사 연결 에서 서비스의 접근 권한을 철회할 수 있습니다. 철회하면 서버에 보관된 토큰은 더 이상 사용할 수 없으며, 운영팀은 요청 시 해당 토큰 파일을 삭제합니다.
